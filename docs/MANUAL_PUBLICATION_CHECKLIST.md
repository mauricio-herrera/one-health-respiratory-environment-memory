# Manual publication checklist

- [ ] Final article title.
- [ ] Complete author list and order.
- [ ] Affiliations and ORCIDs.
- [ ] Corresponding author.
- [ ] GitHub repository name and URL.
- [ ] Source-specific redistribution terms for SADU, GRD, DEIS and environmental sources.
- [ ] Final data license.
- [ ] Final code license.
- [ ] Required source attribution text.
- [ ] Funding statement.
- [ ] Ethics/privacy statement for aggregated administrative health data.
- [ ] Zenodo deposition type and metadata.
- [ ] Final Zenodo DOI.
- [ ] Update CITATION.cff with complete authors and repository/DOI.
