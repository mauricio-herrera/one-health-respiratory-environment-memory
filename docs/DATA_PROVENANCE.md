# Data provenance

This public release is built only from frozen publication-level artifacts that
passed the local audit pipeline.

No raw SADU, GRD or DEIS acquisition archives and no establishment-level files
are copied into the release.

The historical panel is the frozen 2019–2024 canonical region-day panel. The
external 2025 design is health-blind. The SADU 2025 target is the source-truth
365×11 aggregate frozen before external scoring.

`SOURCE_PROVENANCE.csv` records exact local upstream paths and SHA256 hashes for
the source artifacts used to build this release.

Source-specific redistribution terms must still be reviewed manually before
public deposition.
