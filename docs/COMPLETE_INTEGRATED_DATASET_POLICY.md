# Complete integrated dataset release policy

This project follows an **all-or-complete** publication policy.

The scientific dataset is intended to remain useful for independent
reproducibility and secondary research. For that reason, publication does not
remove individual source families merely to simplify licence metadata.

The release instead:

1. keeps the integrated dataset complete;
2. identifies all source organizations;
3. distinguishes original public data from author-generated derived variables;
4. preserves source-specific attribution/reuse notices;
5. makes no ownership claim over source observations;
6. licenses only original project code under the included MIT licence; and
7. asks downstream users to respect the terms of the original sources.

No partial-data public release is produced by this stage.
