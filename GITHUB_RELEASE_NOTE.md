# GitHub release note

This repository publishes the complete integrated One-Health research dataset
and reproducibility package, version 1.0.0.

The research team does not claim ownership of the underlying public source
observations. The original contribution consists of data integration, cleaning,
harmonization, quality control, derived variables, memory construction,
modelling, numerical auditing, external validation, uncertainty analysis, and
reproducibility infrastructure.

See:
- `README.md`
- `DATA_RIGHTS_NOTICE.txt`
- `docs/DATA_OWNERSHIP_INTEGRATION_AND_REUSE.md`
- `docs/SOURCE_ATTRIBUTIONS.md`
- `docs/SOURCE_RIGHTS_POLICY.csv`
- `docs/SINCA_ACADEMIC_USE_NOTE.md`

The archival dataset DOI will be added after the Zenodo v1.0.0 record is
published.
